| | 颜色①（第1周） | 颜色②（第8周） | 颜色③（第20周） | 颜色④（第39周） |

| **词汇** | red, blue, yellow, green | + pink, purple | orange, white, black, gold | 颜色+形状 circle, square, star |
| **句型** | "It's red." | "Which is blue?" "I like pink." | "My favorite is..." | "A red circle." "The star is yellow." |
| **你问她** | "What color is this?" | "Which one is red?" | "What color do you like?" | "How many red stars?" |
