# 谦灵启蒙 App · 设计文档

> 日期：2026-09-09
> 状态：Mei 已批准方案，本文档待复核后进入实施计划

## 1. 背景与目标

Mei 在 `E:\谦灵英语启蒙\` 有完整的女儿英语启蒙年度规划（48周、四阶段、七大主题循环）。每周细化内容以 docx 三件套交付（详细计划 / 配套讲义 / 冰箱贴）。第1周 Colors 已教完，效果不错。

**问题**：每次备课要开电脑翻 docx，手机没法快速查看。

**目标**：做一个手机 App（网页版 PWA，装到主屏幕），打开就能看到本周该教什么、每天说什么，随时备课，轻量打卡。**核心就是：简洁的备课教案 + 打卡，打开立刻能用。**

**非目标**（明确不做）：
- 不做朗读/发音功能（App 是 Mei 自己备课用的，不需要 TTS）
- 不在 App 里播放视频（SSS 视频在电脑E盘，App 只提醒"今天看哪首"）
- 不在 App 里生成新周内容（生成仍在电脑上由 Claude 完成，App 只展示）
- 不做多用户、不做账号系统（就 Mei 一个人用）
- 不打印输出（打印件仍走 docx 流程，App 不管）

## 2. 使用场景

1. 早上醒来打开手机 → 看今天（如"第2天·蓝色日"）要做什么、说什么 → 去执行
2. 上课前扫一眼核心词和核心句 → 张口就说，不用记
3. 每天做完 → 打勾 → 本周进度一目了然
4. 想看看后面几周学什么 → 全年地图页翻看骨架

## 3. 页面结构（3个页面）

单页应用内切换视图，无路由框架（与旧 app 一致）。

### 3.1 本周页（首页，打开即见）

- 周标题大字：`第2周 · 🐱 Animals 动物`
- 核心词卡片（英文大字 + 中文小字）
- 核心句卡片（英文大字）
- 视频提醒条：`本周主视频：Old MacDonald（016）`（只提醒，不放视频）
- 7天列表：每天一行，显示「第X天 · 标题」+ 完成勾；点击进入当天详情
- 底部周切换：`◀ 第1周 | 第2周 | 第3周 ▶` + 「全年地图」入口
- 默认打开第2周（第1周已教完）；用户手动切过之后记住选择（localStorage）

### 3.2 当天详情页（核心备课页）

- 顶部：`第2天 · 蓝色日` + 完成状态
- 按时间段分块（穿衣服 / 早餐 / 上午 / 晚饭后 / 睡前……），每块：
  - 「做什么」中文一句
  - 「说这句」英文原句大字（照着读就行）
- 「今天只需记」提示条（醒目色块）
- 进阶内容（选做）折叠区
- 休息日（如第3天）显示休息说明，无时间段块
- 底部大按钮「✅ 今天完成啦」，点按切换完成状态（可取消）

### 3.3 全年地图页

- 48周网格，每格：周次 + emoji + 主题名 + 核心词摘要（来自年度规划表）
- 已细化的周（1-4）有完整内容，可点击进入；未细化的周显示骨架信息 + 灰化标记「内容还没出」

## 4. 内容数据设计

### 4.1 两层内容

- **骨架层**：48周全表（周次、日期、主题、核心词、核心句型），从 `年度规划-谦灵英语启蒙.md` 的周排表直接转换，App 首版即内置全部48周
- **细化层**：每周完整内容（每天分时段的做什么/说什么、视频、进阶内容）。首版内置第1-4周；第5周起按 §6 流程逐周补充

### 4.2 数据文件

单个 `content.json`（预估48周全量 < 300KB，可接受），结构：

```json
{
  "version": 1,
  "weeks": [
    {
      "week": 2,
      "stage": 1,
      "dates": "7/6-7/12",
      "theme": "动物①",
      "themeEn": "Animals",
      "emoji": "🐱",
      "coreWords": [{"en": "dog", "zh": "狗"}],
      "coreSentences": ["I see a dog."],
      "detailed": true
    }
  ],
  "details": {
    "2": {
      "video": {
        "primary": {"name": "Old MacDonald", "no": "016"},
        "advanced": {"name": "……", "no": "……"}
      },
      "days": [
        {
          "day": 1,
          "title": "红色日",
          "sections": [
            {"time": "穿衣服", "do": "挑红色衣服", "say": ["Let's wear your red shirt! Red!"]}
          ],
          "remember": "一切红色 = Red!",
          "advanced": "进阶词……",
          "rest": false
        }
      ]
    }
  }
}
```

- `detailed: false` 的周只渲染骨架，点击提示「内容还没出」
- 7天全覆盖（含休息日，`rest: true`），保证进度点对齐7天
- 第1-4周内容从现有 docx（详细计划 + 冰箱贴）人工转录进 JSON，转录时核对两处信息一致性

## 5. 打卡设计

- 存储：手机本地 `localStorage`，键 `qianling-progress-v1`，结构 `{"2": {"1": true, "2": false}}`（周 → 天 → 完成）
- 不需要 GitHub 写入权限、不需要登录（单用户，本地就够）
- 本周页显示7天进度点；当天详情页大按钮切换完成状态
- 换手机不迁移（可接受，打卡只是辅助）

## 6. 更新与发布流程

### 6.1 每周新内容固定流程（以后都这样）

Mei 喊「出第X周细化版」时：

1. 照常生成 docx 三件套（详细计划 / 配套讲义 / 冰箱贴）到 `E:\谦灵英语启蒙\第X周-主题\`
2. 同时把该周内容转录进 App 的 `content.json`（`detailed: true`）
3. `content.json` 版本号 +1，推送 GitHub
4. 手机端 App 下次打开自动拉到新内容（内容用网络优先策略，见 §6.2）

### 6.2 版本与缓存策略

- 页面代码（index.html / sw.js 等）更新：沿用五人打卡的 `version.json` + Service Worker 缓存名 + 「点我更新」提示机制
- `content.json`：每次加载走网络优先（带版本参数防缓存），拿不到网络就用缓存兜底——保证内容更新不依赖用户点「更新」

## 7. 技术路线

- **纯前端单页**：一个 `index.html`（HTML+CSS+JS 全含），无框架、无构建步骤，与灵感骰子 / 五人打卡一致
- **PWA**：`manifest.json`（应用名「谦灵启蒙」）+ `icon-192.png` / `icon-512.png` + `sw.js`，可添加到手机主屏幕
- **托管**：GitHub Pages，仓库名 `qianling-english`（新建公开仓库；免费版 Pages 要求公开，与旧 app 相同）
- **无后端、无凭证、无第三方 API**

- 参考灵感骰子的完成度和五人打卡手账风，但更明亮童趣
- 具体配色、字体、组件在实施阶段用 frontend-design 技能细化

## 10. 验收标准

1. 手机上（Mei 的实际设备）通过 GitHub Pages 打开，正常显示第2周内容
2. 第1-4周全部内容可浏览，当天详情分时间段清晰可读，一眼能看到"做什么、说什么"
3. 打卡可打勾、可取消，本周页进度正确
4. 全年地图48周齐全，未细化周显示「内容还没出」
5. 可添加到主屏幕，断网也能打开（PWA 缓存生效）
6. 更新 `content.json` 推送后，手机端能拉到新内容
